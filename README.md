# Olivia Kart Race

Juego de karts arcade 3D original, construido con Three.js y Vite.

## Jugar en local

```bash
pnpm install
pnpm dev
```

## Controles

- `W` / `↑`: acelerar
- `S` / `↓`: frenar o retroceder
- `A` / `←`: girar a la izquierda
- `D` / `→`: girar a la derecha
- `Shift`: derrape y mini-turbo
- `Espacio`: usar objeto

El proyecto se publica automáticamente en GitHub Pages al actualizar `main`.
